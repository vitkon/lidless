lidless
How it works Install GitHub

Shut the lid.The work keeps going.

lidless keeps your MacBook awake with the lid closed, on battery, for as long as Claude Code or any other job is running. Start a Remote Control session, close the laptop, and carry on from your phone.

$ brew install vitkon/tap/lidless

Then run lidless setup once. macOS command-line tool, free and open source.

$ lidless status
SleepDisabled  1 (Mac stays awake)
power          battery, 64%, thermal nominal
holds
  [4812] holding, claude busy for 3m
         claude --remote-control

Wrap the command. That's the whole interface.

Put lidless in front of anything. While it runs, the Mac won't sleep, even with the lid shut. When it ends, sleep comes back on its own.

# a Remote Control session you'll drive from your phone
$ lidless claude --remote-control

# a long build, then put the Mac to sleep when it's done
$ lidless --sleep-after npm run build

# see what's keeping the Mac awake
$ lidless status

# let it sleep right now
$ lidless release

Knows when Claude has gone quiet

For claude sessions, lidless listens to Claude Code's own hooks, so it can tell a session that's working from one that's waiting. Your global settings are never touched; the hooks exist only for that run.

Every 30 seconds it checks these rules in order. The first one that matches decides.

  1. You pressed releaseRunning lidless release lets the Mac sleep for the rest of that run.
  2. Battery is nearly emptyOn battery at 10% or less, the Mac is allowed to sleep, so it can resume later instead of shutting down.
  3. The chip is running hotIf macOS reports serious thermal pressure, lidless lets go until things cool down.
  4. Claude has been idle for 30 minutesThe session keeps running. Send a new prompt and the Mac is held awake again.
  5. Otherwise, stay awakeThe job is active, so the Mac stays on.

Built so it can't strand your Mac awake

Keeping a closed laptop awake changes a system-wide setting. lidless treats putting it back as its most important job.

Crash recovery
A small background watchdog checks every minute. If a lidless process dies without cleaning up, sleep is switched back on.
Several jobs at once
Each job gets its own hold. The Mac can sleep again only after the last one finishes.
Narrow permissions
Setup adds one sudoers rule that allows exactly three pmset commands. Nothing else runs as root.
Phone alerts
Get a push notification through ntfy or any webhook when the battery runs low, the Mac gets hot, Claude goes idle, or a long job finishes. Alerts go out before the Mac is allowed to sleep.
Your limits
Idle timeout, battery floor and heat limit live in ~/.lidless/config.json.

Install

Needs macOS 13 or later and Xcode or the Command Line Tools. Homebrew builds it from source; you can also clone the repo and run make install.

Update later with brew upgrade lidless.

  1. Install with Homebrew. 
    $ brew install vitkon/tap/lidless
  2. Run setup once. It asks for your password to add the sudoers rule and the watchdog. 
    $ lidless setup
  3. Optional: get alerts on your phone. Install the ntfy app, subscribe to a long random topic, and add it to ~/.lidless/config.json. 
    $ echo '{"alerts": {"ntfyTopic": "your-random-topic"}}' > ~/.lidless/config.json
$ lidless test-alert
  4. Start a session, close the lid, pick up your phone. 
    $ lidless claude --remote-control
